# Vision

- tlh gui is the graphical home for The Last Harness; the [TLH vision](https://github.com/diegopetrucci/the-last-harness/blob/main/VISION.md) applies here too.
- Users stop caring about branch management: they start a new chat and that's it. Each new chat works in its own worktree by default, on desktop and mobile, and tlh gui handles the git plumbing.
